How this site works

The site is itself an example of docs as code:

  • Plain files: every page is an HTML file. There is no database and no server-side code, so it runs offline straight from a folder.
  • Version control: all files live in a Git repository on GitHub. Every change is recorded with its author, date and reason.
  • Single source of truth: the navigation menu is defined once in assets/js/site.js and used by every page.
  • Generated search index: a small script reads every page and builds the search index automatically.
  • Free hosting: the site can be published with GitHub Pages. Every change pushed to the repository goes live automatically.

Adding or updating a page

  1. Copy an existing pagein the same folder and change its title, data-page and content.
  2. Add it to the navigationin the NAV list at the top of assets/js/site.js.
  3. Rebuild the search index. 
    node scripts/build-search-index.mjs
  4. Update the page's data-updated date and version, then commit with a clear message, e.g. docs: add VPN setup SOP.
