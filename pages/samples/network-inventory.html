Why “Confidential”?

A network map is as useful to an attacker as it is to an administrator. Share this document only with staff who need it, and never post it publicly.

Tip

Compare “Owned” and “In use” every quarter. Using more than you own breaks license terms (see Ethics: licensing). Paying for far more than you use wastes money.

Naming conventions

  • Hostnames: role-NN, lowercase, two-digit number, e.g. web-01.
  • Network devices: type-location-NN, e.g. sw-core-01.
  • Gateways: always .1 in each subnet.
  • Static server addresses: grouped by role in tens (.10 directory, .20 files, .30 backup, .40 web).
