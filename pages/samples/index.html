Sample Documents

These are the documents a real system administration team writes and maintains. They apply everything from the three report topics, written for Example Corp, a fictional company.

About the examples

Example Corp, its people, servers and IP addresses are fictional. The domain example.com and the public address range 203.0.113.0/24 are reserved for documentation (RFC 2606 and RFC 5737), as recommended in our style rules.

How the documents connect

Documents rarely stand alone. In this example set:

  • The incident report found a gap, an undocumented temporary change, which led to updates in the change management policy and the runbooks.
  • The change request uses the server inventory to list affected systems and relies on backups from the runbook as a safety net.
  • The SOP implements the Password and Access Control policies.
